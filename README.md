# SD Apoio Comercial — Sophia Dadalt

Landing Page Editorial de Alta Conversão para a **SD Apoio Comercial**, liderada por Sophia Dadalt.
Assessoria e Organização Comercial Remota B2B especializada em estruturação de processos, qualificação de oportunidades, organização de CRM e follow-up ativo para Pequenas e Médias Empresas (PMEs).

## 🚀 Tecnologias Utilizadas

- **Next.js 16** (App Router, Turbopack)
- **React 19**
- **TypeScript** (Strict mode)
- **Tailwind CSS v4**
- **GSAP & ScrollTrigger** (`@gsap/react`, `useGSAP`)
- **Lucide React** (Ícones padronizados)

## 🎨 Design System Editorial

- **Paleta de Cores:**
  - Charcoal Editorial: `#0F0F11` e `#17171A`
  - Acentos Metálicos: Ouro Champanhe `#D4AF37` e `#E2D9D2`
  - Tipografia Nobre: Branco Puro `#F5F5F7` e Cinza Muted `#A1A1AA`
- **Pares Tipográficos:**
  - Títulos: *Cormorant Garamond* (Google Fonts)
  - Corpo & UI: *Plus Jakarta Sans* (Google Fonts)

## 💼 Funcionalidades & Dobras

1. **Navbar Editorial:** Sticky com blur, monograma "SD" e CTA rápido.
2. **Hero Split:** Proposta de valor clara, fotografia com recorte editorial e selos de conformidade.
3. **Diagnóstico da Realidade:** Comparativo da rotina tradicional desorganizada vs. rotina ativa da SD.
4. **Bento Grid de Serviços:**
   - Organização de CRM & Gestão de Contatos
   - Follow-up Ativo de Orçamentos
   - Prospecção Ativa B2B
   - Atendimento & Apoio Comercial Remoto
5. **Sobre Sophia Dadalt:** Posicionamento de liderança, pilares de atuação e modelo B2B sem vínculo CLT.
6. **Depoimentos Estruturados:** Casos reais de PMEs com métricas comprovadas.
7. **Accordion Interativo (FAQ):** Respostas sobre contratação sem CLT, ferramentas/CRMs, sigilo LGPD e diagnóstico inicial.
8. **Localização, Horários & Redes:** Horários de atendimento, cobertura remota nacional (Santa Catarina - DDD 49) e Instagram `@apoiocomercial.sd`.
9. **Floating WhatsApp CTA:** Botão flutuante mobile/desktop com animação de ping e mensagem personalizada.

## 🛠️ Executando Localmente

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
